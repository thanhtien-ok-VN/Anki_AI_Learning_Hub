🚀 AI Learning Hub for Anki

8 Gamified AI-Powered Language Learning Games (Powered by Google Gemini API)

🌟 Overview

AI Learning Hub transforms your Anki vocabulary review into an engaging, interactive learning experience with 8 intelligent AI game modes. Utilizing cutting-edge Google Gemini AI, the add-on automatically generates context-rich exercises, provides 5-field granular error analysis, offers multi-tier hints, and supports full multilingual learning (English & Chinese target languages with English & Vietnamese UI).

📌 Step-by-Step Setup Guide

1️⃣ Step 1: Install the Add-on in Anki
  1. Open Anki Desktop on your computer.
  2. On the top menu bar, navigate to Tools ➔ Add-ons (or press Ctrl + Shift + A on Windows / Cmd + Shift + A on Mac).
  3. Install via AnkiWeb Code: Click Get Add-ons... ➔ Paste the 9-digit code ➔ Click OK.
  4. Install via File (.ankiaddon): Click Install from file... ➔ Select the AI_Learning_Hub.ankiaddon file.
  5. Restart Anki to complete activation.
2️⃣ Step 2: Get a Free Gemini API Key (Google AI Studio)

The add-on connects directly to Google Gemini AI to generate exercises. You can obtain a free API Key in less than 1 minute:

  1. Visit Google AI Studio: https://aistudio.google.com/app/apikey
  2. Sign in with your Google account (Gmail).
  3. Click the Create API key button.
  4. Select or create a project ➔ Google will display a long API Key string starting with AQ...
  5. Click Copy to copy your API key to clipboard.
3️⃣ Step 3: Add API Key & Run Connection Test
  1. In Anki, navigate to Tools ➔ 🚀 AI Learning Hub...
  2. Once the Hub opens, click the ⚙️ Settings button at the top right corner.
  3. In the Gemini API Keys box, paste your API Key starting with AQ... (one key per line if you have multiple keys).
  4. Click 🧪 Test All Keys:
    • 🟢 Displays green Active: Your key is valid and ready to use!
    • 🔴 Displays red: Double check if any characters were missed during copy.
  5. Click 💾 Save Settings to store your key securely.
4️⃣ Step 4: Configure Learning Language & Anki Deck Source
  • Learning Language: Select your target language (e.g., English, Chinese (Mandarin)). Generated exercises will be 100% in this language.
  • UI & Feedback Language: Choose English or Vietnamese. Interface labels, hint titles, and AI error explanations adapt dynamically to your choice.
  • Anki Deck Source: Select any vocabulary deck from your Anki collection. The AI will extract word pairs directly from your cards!
5️⃣ Step 5: Practice Across 8 AI Game Modes

Choose any of the 8 game modes from the home screen to begin practicing:

✏️ 1. Fill in the Blank:
Fill missing target words in context sentences. Interactive Blank Pills allow smooth answer placement.
📖 2. Cloze Test:
Read coherent topic paragraphs and complete multiple blank positions ([BLANK_1], [BLANK_2]...).
🌐 3. Sentence Translation:
Translate sentences into target languages. AI grades 0-10 and details 5 error fields (Category, Incorrect segment, Reason, Suggestion, Rationale).
🧩 4. Sentence Unscramble:
Reorder scrambled word tiles into grammatically correct sentences.
📚 5. Story Generator:
AI generates level-tailored reading passages (CEFR A1-C2) with 4-choice comprehension questions (Main Idea, Detail, Vocabulary).
🔄 6. Sentence Transformation:
Rewrite sentences according to grammar prompts (Passive voice, Conditionals...). Provides unified 4-block feedback with common & advanced suggestions.
🚫 7. Taboo Word Guessing:
Guess target words from AI descriptions without using forbidden (Taboo) words.
🔗 8. Word Matching:
Match terms and definitions extracted from your Anki deck. Operates 100% offline without API calls.

💡 Multi-Tier Hint System & Exercise History

  • 💡 Multi-Tier Hint System: 3-tier progressive hints (Level 1: Grammar Rule, Level 2: First Letter & Meaning, Level 3: Full Solution). Automatically calculates tiered score penalties.
  • 📜 Exercise History: Review detailed past exercise attempts, scores, hint penalty badges, and AI explanations anytime.
